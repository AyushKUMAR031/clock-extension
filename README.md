# Clock Extension

A minimal and elegant Chrome Extension that displays a real-time digital clock in your browser tab. Built using plain HTML, CSS, and JavaScript — no frameworks or libraries required.

---

## Features

- Real-time digital clock
- Lightweight and fast
- Auto-updates every second
- Clean and minimal UI

---

## Project Structure

    clock-extension/
    ├── manifest.json # Chrome extension config
    ├── index.html # Clock interface
    ├── style.css # Styling
    └── script.js # Clock logic

---

## Setup Guide

### 1. Clone the Repository

```bash
1.
git clone https://github.com/your-username/clock-extension.git

2.
Open Chrome Extension Page

3.
Go to: chrome://extensions

4.
Enable Developer Mode

5.
Toggle the Developer mode switch in the top-right corner.

6.
Load the Extension

7.
Click on Load unpacked

8.
Select the folder where this extension is located (clock-extension/)

9.
Done! You should now see your clock extension running.

```
